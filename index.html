NAME

ai — how Andrey puts language models to work

SYNOPSIS

Not chat windows. Services that plan, write, answer and get reviewed before they act.

DESCRIPTION

Everything here runs in production for a real company, with budgets, logs and a human in the loop where it matters.

COMPONENTS

agents — sales assistant with approval loop
Answers Messenger leads, keeps memory in SQLite with vector search, escalates drafts to Telegram for a human yes/no. Rebuilt from n8n flows into a FastAPI service.
pipelines — content on autopilot
Weekly LLM planning of a posting calendar, drafts, images and publishing through LinkedIn and Facebook APIs. Scheduler with re-entry guards and crash-safe migrations.
gateway — one LLM proxy for all services
Shared LiteLLM gateway with model routing per project and cost control. A model audit cut spend by moving defaults to cheaper models where quality allowed.
editors — article and image tools
AI article editor and image generator for the marketing team, with per-user quotas and a log of who generated what.
